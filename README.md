# teorias-evolutivas

Recursos interactivos para la clase de Ciencias Naturales.

- `index.html` — Quiz interactivo: Fijismo, Lamarckismo y Selección Natural.
- `bioacumulacion.html` — **Cadena Tóxica**: juego de bloques para modelar la bioacumulación y la biomagnificación. Una fábrica vierte residuos a un lago con fitoplancton, plantas, zooplancton, peces y una garza; el contaminante se acumula en cada organismo y su concentración se multiplica al subir por la cadena trófica. Incluye misiones guiadas, pirámide trófica en vivo, gráfico histórico y una guía con casos reales y preguntas para discutir.

Ambos archivos funcionan sin instalación: basta con abrirlos en el navegador.
